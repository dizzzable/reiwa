# Свои формулировки в кабинете

Кабинет читает отсюда файл с вашими строками и накладывает их **поверх**
встроенного словаря. Пересобирать образ не нужно.

## Как

1. Возьмите за основу `ru.override.example.json` рядом.
2. Оставьте в нём **только те ключи, которые хотите изменить**.
3. Смонтируйте файл в контейнер:

```
# образ SPA (nginx)
-v ./ru.override.json:/usr/share/nginx/html/locales/ru.override.json

# объединённый образ (API раздаёт SPA сам)
-v ./ru.override.json:/app/web/locales/ru.override.json
```

Английский — тот же путь с `en.override.json`.

4. Обновите вкладку кабинета. Контейнер перезапускать не нужно.

## Почему «поверх», а не «вместо»

Файл, заменяющий словарь целиком, устаревает с первым же обновлением: мы
добавляем ключи, ваша копия про них не знает, и на экране появляются пустые
места. Накладка называет только ваши строки — всё остальное продолжает
приезжать из сборки и обновляться вместе с ней.

Убрать формулировку накладка не может, только заменить: ключ, которого в ней
нет, берётся из встроенного словаря.

## Что нужно знать

- **Множественное число — это четыре ключа, а не один.** Для русского:
  `_one` (1 вариант), `_few` (2 варианта), `_many` (5 вариантов) и `_other`.
  Задав только `_one`, вы измените строку лишь для единицы.
- **`{{count}}` и другие подстановки надо сохранить.** Стёрли — потеряли число
  или имя, которое туда подставлялось.
- **Ключ должен существовать.** Опечатка ничего не сломает, но и ничего не
  изменит: такой ключ просто не с чем связать. Актуальный список смотрите в
  `web/src/i18n/ru.ts` вашей версии.
- **Сломанный JSON игнорируется целиком** — кабинет покажет встроенные строки.
  Проверить можно любым валидатором JSON до монтирования.
- **HTML не работает.** Строки выводятся как текст, теги будут видны как теги.
- **Файл не кэшируется** ни браузером, ни service worker'ом — правка видна
  сразу после обновления вкладки.

## Пример

Из реального обращения: подпись «1 вариант срока» на карточке тарифа звучала
канцелярски. Рядом на той же карточке уже написана цена «от ₽199.00» и срок
«от 30 дн», так что слово «срока» лишнее:

```json
{
  "plans": {
    "durationOptions_one": "{{count}} вариант",
    "durationOptions_few": "{{count}} варианта",
    "durationOptions_many": "{{count}} вариантов",
    "durationOptions_other": "{{count}} вариантов"
  }
}
```
